# Data and code for PRLETTERS-D-26-01198

This repository contains the data, code, configuration files, and validation records supporting the revised manuscript “Multilingual suffix sensitivity in large language model exact-answer delivery” (PRLETTERS-D-26-01198). It includes the repeated 1.5B and 7B experiments, paired token-budget analyses, failure-state diagnostics, language-detector validation records, and supporting reproducibility materials. Third-party tokenizer and configuration files retain their original licenses.

**Version:** 1.0.0

## Authors

Shuo Wang, Chen Guo, Bingxin Yang, Yu Zhang, Keran Hao.

All authors: Chang'an University.

## Download and use

1. Open this repository's **Releases** and select version **1.0.0**.
2. Download the release asset **`Revision_Data_and_Code_Full.zip`**. The archive is distributed through Releases, rather than the repository's Git files.
3. Extract the complete archive while preserving its directory structure.
4. Read **`README.md` at the extracted archive root** for the file map, dependencies, CPU verification commands, and reproduction instructions.

The archive includes all **14,550 formal raw completions and complete token ID sequences**, alongside the original scientific records and supporting materials. Run the documented commands from the extracted archive root. Use a separate working copy when rebuilding derived outputs.
